UE4 Tornado

A tornado physics system created for Brick Rigs, featuring dynamic forces that interact with vehicles and players.

About the Project

This project is a custom tornado system created as a mod for Brick Rigs using Unreal Engine 4.

The goal was to create a tornado that could dynamically affect objects around it instead of simply using a predefined animation.

The system calculates the relationship between the tornado and nearby objects and applies forces based on their position relative to the tornado.

This allows vehicles and other physics objects to be pulled toward the tornado, moved around its center, and affected by its changing forces.
